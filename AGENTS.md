# Architecture rules
- Calculate prayer times on-device using Adhan and coordinate-based timezone lookup; coordinates must not be sent to a prayer-time service.
- Persist prayer settings and location with Capacitor Preferences on native devices (migrate legacy localStorage), and localStorage on web; hydrate before rendering routes or refreshing reminders, and save independently of scheduling success so notification failures never discard choices.
- Keep advance reminders separate from Adhan playback; schedule full bundled Adhan with native exact alarms and a mediaPlayback foreground service with manual stop, because Android notification sounds cannot reliably play full recordings. Persist the alarm plan and restore its next future alarm on reboot; require user-granted SCHEDULE_EXACT_ALARM, never USE_EXACT_ALARM. Full manual web playback uses the licensed asset pointer.
- Calculate Qibla locally with Adhan; use a registered Android Compass plugin with rotation-vector sensors and geomagnetic declination for true-north heading, and never substitute relative browser orientation for north.
- Keep electronic tasbih count in device-local storage, independent of Adhkar counters, so counting survives reopening without changing existing reminders.
